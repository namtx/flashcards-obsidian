# Flashcards 2.3.0

## Type in the answer

A new card type asks you to type the answer during review. Anki then compares
your input with the expected answer.

```markdown
Capital of France?:=:Paris
```

Fenced cards accept `type: type-in`. Cards use the new `Obsidian-type-in` note
type, which the next sync creates automatically. Changing an existing `::`
card to `:=:` converts its Anki note in place and keeps its review history.
The separator is configurable with `inlineTypeInSeparator`.

If you previously edited the `Obsidian-basic` templates to add `{{type:Back}}`,
you can switch those cards to `:=:` and restore the default basic templates.
